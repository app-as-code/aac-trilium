# Icon source

The icon is downloaded from the homarr-labs dashboard icon collection
(repository `homarr-labs/dashboard-icons`, served via jsdelivr). No icon was drawn or
modified by hand.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `svg/trilium.svg` | Default icon (light and dark mode) |

Download URL:

- https://cdn.jsdelivr.net/gh/homarr-labs/dashboard-icons/svg/trilium.svg

No light/dark variants (`trilium-light.svg`, `trilium-dark.svg`) exist in the collection,
so a single icon is used for both color schemes.
